# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please DO NOT open a public issue for security problems.
Use GitHub's private reporting: **Security tab → Report a vulnerability**,
or contact the maintainer via github.com/eh3n.

You can expect an initial response within a few days.

## Scope notes
Jarchi is designed for trusted LANs. Do not expose port 8080 or SIP ports
to the public internet, and always change the default admin password.
